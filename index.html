Primera vez: cómo entrar

Se entra con un token de GitHub (una contraseña larga hecha para esto). Se pega una vez por navegador y se queda guardado hasta que cierres sesión.

  1. Entra en GitHub con una cuenta que sea miembro de ciaVENDAVAL.
  2. Abre New fine-grained token.
  3. Token name: Victoria Sickness admin. Expiration: hasta un año.
  4. Resource owner: ciaVENDAVAL.
  5. Repository access: Only select repositories → victoriasickness-web.
  6. Permissions → Repository permissions → Contents: Read and write.
  7. Generate token, cópialo, abre Formularios, elige Sign In Using Access Token y pégalo. Editar en la página usa el mismo token (o lo pide una vez).

Si ciaVENDAVAL no permite tokens fine-grained, usa un token clásico marcando solo public_repo.

Guarda el token como una contraseña. Si se filtra, bórralo en GitHub (Settings → Developer settings) y haz uno nuevo.

Cómo funciona
  • Cada Guardar (o Publicar en la página) va directo a la web. Se ve en unos 3–5 minutos (la web se reconstruye sola; recarga la página).
  • Todo cambio queda en el historial de GitHub: todo se puede deshacer.
  • Cambia un idioma, los demás le siguen: un texto cambiado solo en un idioma se traduce a los otros 7 unos minutos después, con el traductor libre de Softcatalà (sin Google, sin Amazon). Revisa siempre el resultado, sobre todo los pronombres neutros de Vic (they / elle / elli). Para corregir solo un idioma, desmarca Traducir en la barra de edición, o cambia todos los idiomas en el mismo guardado.
  • Fotos: súbelas tal cual (nombres simples sin espacios ni acentos, p. ej. invocaciones-ensayo-3.jpg). El original se guarda intacto en source-images/; la web hace sola las copias grandes y pequeñas. Nunca se recortan.
  • Cambiar una foto sin tocar textos: en la página, tócala y elige otra; o en Formularios → Assets → la foto → ⋮ → Replace.
  • Pon el nombre de quien hizo cada foto en Créditos de las fotos.
  • En el móvil también funciona: el menú de los formularios está detrás de ☰.
  • Los PDFs de dossier se hacen con Claude (desde sus fuentes); aquí solo se sube y se elige cuál da cada enlace.
